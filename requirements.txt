# CAGE-Cal — Python dependencies (Python 3.12, CUDA 12.x).
#
# Install:
#   conda create -n cagecal python=3.12 -y && conda activate cagecal
#   pip install -r requirements.txt
#
# Notes:
#   - torch is pinned to a +cu128 wheel. If your machine has a different
#     CUDA version, install the matching torch / torch-geometric wheels
#     from https://pytorch.org and https://pytorch-geometric.readthedocs.io.
#   - vllm is only needed to serve the local open-weight backbones for the
#     panel-generation stage. If you generate panels with hosted APIs
#     instead, vllm can be omitted.
#   - `calibration` is the `uncertainty-calibration` package (Kumar et al.,
#     2019); it provides PlattBinnerCalibrator used by the post-hoc step.
